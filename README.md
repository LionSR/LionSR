# Sirui Lu 👋

## 🤖 Agents and formal verification

- **[TeXRA](https://texra.ai):** I designed and built a multi-agent harness with Wolfram algebra and Lean proof checking. TypeScript; editor extensions and CLI; specialist agents for derivation, computation, and review.
- **[FormalFlow / MIPStarRE](https://github.com/LionSR/MIPStarRE):** with collaborators, formalized quantum soundness of the classical low individual-degree test, a core theorem underlying MIP\* = RE. **63-day proof effort**; **126,367 lines of Lean** in the later study snapshot. [Paper](https://arxiv.org/abs/2609.19814)
- **[Quantum-code discovery](https://github.com/LionSR/lean-qec-sslp):** co-designed **14,116 Lean-certified quantum error-correcting codes** using agents, symbolic computation, and search. [Paper](https://arxiv.org/abs/2510.20728)
- **[TNLean](https://github.com/LionSR/TNLean) / [QICLean](https://github.com/LionSR/QICLean):** tensor-network and quantum-information theory in Lean 4/Mathlib, including the fundamental theorem of matrix-product states. [Paper](https://arxiv.org/abs/2607.07857)
- **[Agentic Publication Protocol](https://github.com/LionSR/AgenticPublicationProtocol):** papers packaged with code, data, and instructions for research agents. With Xiao-Liang Qi.
